# YouTube Manager - MongoDB

A simple command-line YouTube Manager application built with Python and MongoDB. The application allows users to store and manage video information using basic CRUD (Create, Read, Update, Delete) operations.

---

## Project Overview

YouTube Manager is a Python-based command-line application designed to manage a collection of YouTube videos.

The application uses MongoDB as its database and provides a menu-driven interface for performing common database operations.

Users can:

* View all stored videos
* Add new videos
* Update existing videos
* Delete videos
* Exit the application

The project demonstrates how Python can interact with a NoSQL database using MongoDB and perform CRUD operations through PyMongo.

# MongoDB Database Structure

MongoDB stores data in the form of **documents** rather than rows and tables.

A typical video document can look like:

```json
{
    "_id": "MongoDB ObjectId",
    "name": "Python Tutorial",
    "time": "10:30"
}
```

### Document Fields

| Field  | Description                                          |
| ------ | ---------------------------------------------------- |
| `_id`  | Unique identifier automatically generated by MongoDB |
| `name` | Name of the video                                    |
| `time` | Duration or time of the video                        |

MongoDB automatically generates a unique `_id` for each document unless one is explicitly provided.

# MongoDB Configuration

This project can use either:

* MongoDB Atlas
* Local MongoDB Server

## Using MongoDB Atlas

Create a MongoDB Atlas cluster and obtain your MongoDB connection string.

The connection string generally follows this format:

```text
mongodb+srv://<username>:<password>@<cluster-url>/
```

Do not publish your actual username, password, or connection string containing credentials on GitHub.

A safer approach is to store sensitive configuration in environment variables.

For example:

```text
MONGODB_URI=your_mongodb_connection_string
```

---

## Using a Local MongoDB Server

If MongoDB is installed locally, the application can connect to a local MongoDB instance using a connection string such as:

```text
mongodb://localhost:27017/
```

The exact connection configuration depends on how MongoDB is installed and configured on your system.

# How to Use

After starting the application, the menu will be displayed.

```text
Youtube Manager | choose an option

1. List all videos
2. Add a video
3. Update a video
4. Delete a video
5. Exit app

Enter your choice:
```

---

## 1. List All Videos

Select:

```text
1
```

The application retrieves the video documents from the MongoDB collection and displays them.

Example:

```text
1. | Python Tutorial | 10:30
2. | HTML Tutorial | 15:20
3. | CSS Tutorial | 20:15
```

MongoDB performs the equivalent of a database read operation using a query such as:

```python
collection.find()
```

---

## 2. Add a Video

Select:

```text
2
```

Enter the video information:

```text
Enter video name: Python Tutorial
Enter video duration/time: 10:30
```

The application creates a MongoDB document and inserts it into the collection.

Example:

```python
video = {
    "name": name,
    "time": time
}

collection.insert_one(video)
```

MongoDB automatically generates an `_id` for the document.

---

## 3. Update a Video

Select:

```text
3
```

Enter the ID of the video you want to update and provide the new information.

The application uses MongoDB's update functionality to modify the selected document.

A typical operation is:

```python
collection.update_one(
    {"_id": video_id},
    {
        "$set": {
            "name": new_name,
            "time": new_time
        }
    }
)
```

The `$set` operator updates the specified fields without replacing the entire document.

---

## 4. Delete a Video

Select:

```text
4
```

Provide the ID of the video you want to remove.

The application uses MongoDB's delete functionality:

```python
collection.delete_one(
    {"_id": video_id}
)
```

The selected document is then removed from the collection.

---

## 5. Exit the Application

Select:

```text
5
```

The application exits the menu loop and terminates.

# MongoDB vs SQLite

This project is also useful for understanding the difference between a relational database such as SQLite and a NoSQL database such as MongoDB.

| Feature            | SQLite              | MongoDB                   |
| ------------------ | ------------------- | ------------------------- |
| Database Type      | Relational          | NoSQL                     |
| Data Structure     | Tables and rows     | Collections and documents |
| Query Language     | SQL                 | MongoDB Query API         |
| Primary Identifier | Primary key         | `_id`                     |
| Python Library     | `sqlite3`           | `pymongo`                 |
| Schema             | Structured          | Flexible                  |
| Storage            | Local database file | Local server or cloud     |
| Cloud Support      | Not built-in        | MongoDB Atlas             |

# Security Considerations

MongoDB credentials should never be hard-coded into a public GitHub repository.

Avoid committing code such as:

```python
MONGODB_URI = "mongodb+srv://username:password@cluster..."
```

Instead, store sensitive information in environment variables or another secure configuration method.

For example:

```text
MONGODB_URI=your_mongodb_connection_string
```

Also make sure that sensitive configuration files are included in `.gitignore`.

Example:

```text
.env
__pycache__/
*.pyc
```
